# 충돌 해소 규칙

합성이 밍밍한 평균이 되지 않기 위한 규칙집.
새 구루 추가 시 기존 규칙과 충돌하는지 점검하고 갱신한다.

## 규칙 작성 형식

```markdown
## 충돌: {{주제}}
- A 진영: {{구루}} — {{입장}}
- B 진영: {{구루}} — {{입장}}
- 해소 규칙: {{어떤 조건에서 어느 쪽이 우선하는지}}
- 적용 예: {{구체 상황}}
```
