## 반영 내용

1. `synthesis/versions/v0.2.md` 신설 (v0.1 복사 후 변경)
   - 「개별 기업 분석 형식」 신설: 판단 프로세스(0~8)를 섹션 순서로 전개. 2번 「기울기」에 분기 실적 표 1개 + 엔진 분해 2~4줄 + **ROE 분해 3~5줄 (필수, 표 아님)**.
   - ROE 분해 기준: 지배주주순이익 / 지배주주 평균자본, 최근 3~5개년(DART 재무제표·주석). ROE = 순이익률 × 자산회전율 × 자기자본승수.
   - 판정 한 줄(마진/회전/레버리지), 레버리지 주도 시 "부채로 만든 ROE" + 통로 게이트 연결, 마진 주도 시 가격결정력 vs 원가 일시 하락 대조, 금융업은 ROA × 레버리지 + BIS·CET1.
   - 판단 프로세스 4단계 직전에 "ROE 분해 원칙" 삽입: 분해 전에는 "질 좋은 ROE"로 서술 금지, 레버리지 주도 상승은 통로 게이트 점검 대상.
   - 8단계에 무효화 조건 작성 규칙 추가: 어느 항(마진/회전/레버리지)이 꺾이는지까지 적기.
   - 「하지 않는 것」에 2항 추가: 단일 수치만 쓰기 금지(한 줄 요약 예외), ROE 분해 표 별도 작성 금지(표 2개 제한 유지).
   - HTML 보고서 반영 규칙 포함 (실적 표 아래 배치, 판정 배지, 레버리지 시 주황 배지).
2. `synthesis/나성의현인.md` frontmatter `version: 0.2`
3. SKILL.md (포터블본 + 로컬본) 데이터 소스 2번 DART에 ROE 분해용 조회법 추가.
4. 새 충돌 규칙(CR) 없음 — 스펙 지시대로 "레버리지 ROE 상승 vs 주주환원 호재" 같은 신호 분기가 반복되면 그때 CR 검토.
