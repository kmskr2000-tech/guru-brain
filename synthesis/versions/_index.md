# 버전 스냅샷 색인

`synthesis/versions/v0.N.md` — 불변 파일. 직접 수정 금지.
백테스트는 항상 이 스냅샷을 입력으로 돌린다 (가변 파일 `나성의현인.md` 금지).

## 버전 올리는 법

1. 소스 흡수 후 `나성의현인.md` 수정.
2. 변경 전이 아니라 **변경 후** 내용을 `versions/v0.N.md`로 복사 (불변 스냅샷).
3. 철학 본문·판단 프로세스·conflict-rules 중 하나라도 바뀌면 minor (+0.1).
   말투·예시만 바뀌면 patch. git tag `guru-v0.N`.
