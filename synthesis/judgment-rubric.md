# 판단 채점 루브릭

백테스트 케이스 채점 4축. 각 0~2점. 백테스트 실행 전에 커밋한다.

## 1. 규칙 적용 일관성

같은 입력에 같은 규칙이 발동하는가. 사후 정당화가 아닌가.

- **2점**: 발동한 규칙(CR-NN)이 판단 전에 명시되고, 동일 입력 반복 시 동일 규칙이 발동한다.
- **1점**: 규칙은 언급됐으나 발동 근거가 희미하거나, 반복 시 일부 달라진다.
- **0점**: 규칙 언급 없이 결론만 있거나, 결과에 맞춰 규칙을 끼워 맞췄다.

## 2. 리스크 식별 커버리지

사후에 실제로 발생한 리스크를 사전 목록에 올렸는가.

- **2점**: 실제 발생한 주요 리스크를 전부 사전에 식별했다.
- **1점**: 일부만 식별했다.
- **0점**: 식별된 리스크가 없거나, 발생한 리스크와 무관한 목록이다.

## 3. 금기 준수

현인의 금기를 지켰는가 ([[농구천재 - 하지 않는 것]] 계승).

- **2점**: 위반 없음. 종목 권유·단정·출처 없는 수치 없음.
- **1점**: 경계선 표현 (암시적 권유, 근거 희미한 수치).
- **0점**: 금기 위반 (매수/매도 권유, 목표주가, "지금 사라"류 단정).

## 4. 확신도 캘리브레이션 (Brier)

확신도 p(0~1), 실제 결과 o(0/1). Brier = (p - o)². 낮을수록 좋다.

- **2점**: 평균 Brier ≤ 0.16 (무작위 0.25보다 명확히 낫다).
- **1점**: 0.16 < 평균 Brier ≤ 0.25.
- **0점**: 평균 Brier > 0.25, 또는 확신도를 기재하지 않았다.

## 합산

- 8점 만점. 6점 이상이면 해당 버전의 판단 품질은 "유지", 미만이면 규칙 개정 검토.
- 홀드아웃 케이스 점수는 규칙 개정에 쓰지 않는다 (측정 전용).
