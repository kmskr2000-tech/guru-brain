# 분석 로그 인덱스

현인 분석 보고서의 복기용 인덱스. 보고서마다 [핵심 판단]·[확신도]·[무효화 조건]·[확인 시점]을 기록하고,
시간이 지나 무효화 조건의 발생 여부를 채점한다.

- 용도: 채점 누적 → 캘리브레이션(확신도 대비 적중률) 측정 → 반복 실패 패턴에서 CR 규칙·프로세스 개선 도출.
- 백테스트(`synthesis/backtests/`)와 짝으로 쓴다.
- 보고서를 현인 철학의 소스로 직접 흡수하지 않는다 (순환 논리 금지).

## 판정 값

- `보류`: 확인 시점 도래 전 또는 아직 채점 안 함
- `유지`: 무효화 조건 미발생 — 판단이 유효한 채로 유지됨
- `무효`: 무효화 조건 발생 — 판단이 틀린 것으로 확정됨

- 복기 리포트 내용: 캘리브레이션(확신도별 적중률), 반복 실패 패턴, CR 규칙·판단 프로세스 개선 제안.
- 개선 제안이 확정되면 버전업으로 반영한다.
